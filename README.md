# makesSENSE
- This is a hackathon project that got us fourth place in design-a-thon held in VIT university (anna auditorium)
- This is an ML based hardware project which we implemented using microchip curiosity nano board and esp32 for the wifi-module.
- The nano board is used with it's dedicated MPLAB X IDE.
- makesSENSE is our team name, and i really don't know how i came up with it but i had to as I was the team leader ;).
